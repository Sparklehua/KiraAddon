#简介

残月哈比快车服务器的整合模组，为 StarRailExpress 提供：

- **吉良吉影（杀手阵营）**：标记、引爆、败者食尘、枯萎穿心攻击等技能；
- **东方仗助（警长阵营）**：疯狂钻石连打、技能清除、复活等技能；
- 角色商店、CCA 组件绑定、网络数据包同步等完整角色系统。

### 前提

构建前需要将 StarRailExpress 及其依赖wathe的jar 放入 `libs/` 目录，详见 `build.gradle`。
